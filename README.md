Social Media & Mental Health Dashboard

Excel Data Analytics Project

📌 Project Overview

This project explores the relationship between social media usage and mental well-being using data visualization techniques in Microsoft Excel.

The analysis focuses on how screen time influences stress levels, sleep quality, happiness, and lifestyle habits, helping identify patterns that affect mental health in today’s digital world.

🎯 Project Objectives

Analyze the impact of screen time on mental well-being

Study variations across different age groups

Understand lifestyle changes related to digital consumption

Present insights using interactive Excel dashboards

📂 Dataset Overview

The dataset captures behavioral and mental health indicators such as:

Screen time duration

Stress levels

Sleep quality

Happiness index

Physical activity levels

Social media usage patterns

🧹 Data Preparation

Created Age Group categories (18–25, 26–35, 36–45, 46+)

Classified Screen Time Levels (Low / Medium / High)

Added Stress Level Categories

Derived Happiness Categories based on index values

🛠 Tools Used

Microsoft Excel

Pivot Tables – for summarizing key metrics

Slicers – for interactive filtering

Charts & Visuals – bar charts, pie charts, and line graphs

📊 Dashboard Overview

The dashboard provides insights into:

Screen time distribution

Stress and happiness correlation

Sleep quality analysis

Platform usage trends

Lifestyle behavior patterns

🔍 Key Insights

Most users fall under medium to high screen-time usage

Higher screen time correlates with increased stress levels

Sleep quality decreases as screen time increases

Physical activity reduces with prolonged device usage

Platforms like YouTube, Instagram, and TikTok dominate usage

📈 Conclusions & Recommendations
Conclusions:

Screen time strongly affects mental well-being

High usage leads to reduced sleep quality and productivity

Digital habits significantly influence lifestyle balance

Recommendations:

Limit screen time to under 4 hours per day

Practice digital detox, especially before bedtime

Encourage offline activities and physical exercise
